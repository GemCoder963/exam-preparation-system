Data Analytics Lifecycle — 6 Phases 10 marks · 2024-25
A · Conceptual

The lifecycle is iterative — not purely sequential. Poor model performance in Phase 4 may require returning to Phase 2 (data preparation), not restarting from Phase 1.

  • Discovery: Identify business problem, understand data requirements, define scope and objectives, frame hypotheses.
  • Data Preparation: Collect and consolidate data; ETL — handle missing values, duplicates, errors; normalize and encode; create analytic sandbox.
  • Model Planning: Choose appropriate analytical methods (regression, clustering); select algorithms based on business needs; define evaluation metrics (accuracy, precision, recall).
  • Model Building: Implement models using Python/R/Scikit-learn/TensorFlow; train on prepared dataset; tune hyperparameters for better performance.
  • Communicating Results: Visualize findings with Tableau/Power BI/matplotlib; present to stakeholders; provide actionable recommendations.
  • Operationalization: Deploy to production environment (real-time or batch); integrate with CRM/ERP systems; monitor and maintain performance over time.

Multivariate Analysis — Factor Analysis · Cluster Analysis · PCA Syllabus Topic
B · Exam Format
Multivariate Analysis is a statistical technique that simultaneously analyzes multiple interdependent variables to understand relationships, reduce dimensionality, and classify data.
  • Factor Analysis: Identifies underlying latent variables (factors) that explain observed data. Reduces large variable set to smaller groups by correlation. Uses PAF or MLE methods. Example: Identifying personality traits (intelligence, extraversion) from observed behavior scores.
  • Cluster Analysis: Groups similar data points without predefined labels. Algorithms: K-Means, Hierarchical, DBSCAN. Example: Customer segmentation — high-value, low-value, occasional buyers.
  • PCA (Principal Component Analysis): Transforms data into linearly uncorrelated principal components. Retains maximum variance while reducing dimensions. Helps visualize high-dimensional data in 2D/3D. Example: Reducing 1000 gene expression features to 10 principal components.
PCA — Principal Component Analysis (Detailed) 10 marks · 2024-25
A · Conceptual (Step-by-Step)
  • Standardize data: Zero mean, unit variance — ensures no feature dominates due to scale.
  • Compute Covariance Matrix: Captures pairwise feature correlations — shows which features vary together.
  • Compute Eigenvectors + Eigenvalues: Eigenvectors = directions of maximum variance (principal components). Eigenvalues = magnitude of variance in each direction.
  • Sort by eigenvalue (descending): Higher eigenvalue = more variance explained = more important component.
  • Select top k components: Choose fewest components whose cumulative eigenvalue sum exceeds 95% of total variance.
  • Project data onto k components: Transformed dataset has k dimensions instead of original n.
ANALOGYPhotographing a 3D object in 2D: PCA finds the angle (projection) that captures the most information. The camera angle that shows the most detail = the first principal component.
B · Exam Format
PCA (Principal Component Analysis) is an unsupervised dimensionality reduction technique that transforms high-dimensional data onto orthogonal axes (principal components) along which variance is maximized.
  • Covariance Matrix: Computed from standardized data — captures how features co-vary.
  • Eigenvectors/Eigenvalues: Eigenvectors = principal component directions; eigenvalues = variance explained — used to rank and select components.
  • Variance Explained: Select fewest components whose cumulative eigenvalue exceeds 95% of total variance.
  • Applications: Feature reduction before SVM/ANN training, image compression, noise removal, 2D/3D visualization of high-dimensional data.

EXAMPLEGenomics: 50 gene expression features reduced to 5 principal components (explaining 97% variance) before classification — training time reduced 90%, overfitting reduced.

PCA is the most widely used preprocessing step in ML pipelines — it combats the curse of dimensionality and improves model training efficiency and generalization.

Bayesian Modeling, Inference & Bayesian Networks APPEARED 2024-25
B · Exam Format
Bayesian Modeling is a probabilistic approach that applies Bayes' theorem to update the probability of a hypothesis as new evidence is observed, enabling uncertainty-aware predictions.
  • Bayes' Theorem: P(A|B) = P(B|A)·P(A)/P(B). P(A) = prior, P(B|A) = likelihood, P(A|B) = posterior.
  • Type 1 — Point Estimation: Finds the single best parameter estimate (Maximum A Posteriori — MAP).
  • Type 2 — Interval Estimation: Provides a credible interval — the range where parameter likely lies (Bayesian analog of confidence intervals).
  • Type 3 — Posterior Predictive Checks: Validates model by comparing predictions to observed data — detects model misspecification.
  • Bayesian Networks: DAG where nodes = variables, edges = probabilistic dependencies, CPTs = conditional probabilities. Application: Disease diagnosis from symptoms.

EXAMPLESpam filter: P(spam) = 0.3 (prior). P("lottery"|spam) = 0.95. P("lottery"|not-spam) = 0.01. Posterior P(spam|"lottery") = (0.95×0.3)/P("lottery") → very high → classify as spam.

Bayesian methods naturally handle uncertainty and missing data, making them the preferred approach in medical diagnosis, risk assessment, and any domain with strong prior knowledge.

SVM — Mathematical Formulation + Kernels 10 marks · 2024-25
A · Mathematical Understanding

Objective: Maximize: 2/‖w‖ (margin width) subject to: yᵢ(w·xᵢ + b) ≥ 1 for all i

Where: w = weight vector (defines hyperplane), xᵢ = input data points, yᵢ = class labels (+1 or −1), b = bias term.

Soft Margin SVM (for noisy data): Introduce slack variables ξᵢ ≥ 0 → yᵢ(w·xᵢ + b) ≥ 1 − ξᵢ

Minimization problem: (1/2)‖w‖² + C∑ξᵢ where C = regularization parameter (high C = small margin, low error; low C = large margin, more error allowed).

Kernel Functions (for non-linear data):

  • Linear: K(xᵢ,xⱼ) = xᵢ·xⱼ — for linearly separable data.
  • Polynomial: K(xᵢ,xⱼ) = (xᵢ·xⱼ + c)ᵈ — for polynomial decision boundaries.
  • RBF/Gaussian: K(xᵢ,xⱼ) = exp(−γ‖xᵢ−xⱼ‖²) — most widely used, handles complex boundaries.
B · Exam Format
SVM (Support Vector Machine) is a supervised learning algorithm that constructs an optimal hyperplane maximizing the margin between class boundaries, using kernel functions to handle non-linearly separable data.
  • Hyperplane: Decision boundary w·x + b = 0; positioned equidistant from support vectors of each class.
  • Support Vectors: Data points closest to the hyperplane — these alone define the hyperplane's position and orientation.
  • Maximum Margin: Width = 2/‖w‖ — maximizing this improves generalization to unseen data.
  • Kernel Trick: Implicitly maps data to higher dimensions without explicit computation — reduces computational complexity.
  • Soft Margin: Slack variables ξᵢ allow controlled misclassification — C parameter governs the trade-off.

ANALOGYSeparating apples and oranges on a table: Find the widest possible gap (maximum margin) between the two groups. A curved bowl (RBF kernel) can separate them even if they're mixed in 2D.

SVM excels in high-dimensional spaces (bioinformatics, text classification) and is robust to overfitting when the margin is large — unlike neural networks which need careful regularization.

★ Time Series Analysis — Linear Systems + Nonlinear Dynamics Syllabus Topic
B · Exam Format
Time series analysis examines data points collected at specific time intervals to identify patterns, trends, and insights for forecasting and understanding temporal behaviors.

LINEAR SYSTEMS ANALYSIS:

  • Definition: Examines linear relationships between past and future values in a time series.
  • AR (Autoregressive) Models: Use past values of the series to predict future values.
  • MA (Moving Average) Models: Use past error terms for predictions — smooths random noise.
  • ARMA Models: Combine AR + MA for better accuracy. ARIMA adds differencing for non-stationary series.
  • Applications: Stock price prediction, GDP/inflation forecasting, electricity demand prediction.

NONLINEAR DYNAMICS:

  • Definition: Analyzes time series with chaotic/nonlinear behaviors that linear models cannot capture.
  • Sensitive dependence: Small changes in initial conditions cause large differences in outcomes (butterfly effect).
  • Techniques: Delay Embedding (phase space reconstruction), Fractal Dimension Analysis, Lyapunov Exponent (measures sensitivity to initial conditions).
  • Applications: Weather prediction, heart rate variability, financial market analysis.

EXAMPLEWeather forecasting uses nonlinear dynamics — atmospheric interactions are chaotic (ARMA alone is insufficient). Hybrid models combining ARIMA with LSTM capture both linear trends and nonlinear patterns.

Fuzzy Logic — Fuzzy Models + Fuzzy Decision Trees APPEARED 2024-25
B · Exam Format
Fuzzy Logic translates real-world uncertain or imprecise data into fuzzy models using linguistic variables and if-then rules, enabling reasoning with degrees of truth rather than binary true/false logic.
  • Extracting Fuzzy Models from Data: Identify patterns in data → convert to fuzzy rules using linguistic variables. Rules expressed as: "IF temperature is HIGH, THEN likelihood of rain is HIGH."
  • Fuzzy Variables: Not crisp values — "low", "medium", "high" with membership degrees (e.g., 30°C is 60% "warm" and 40% "hot").
  • Fuzzy Decision Trees: Combines fuzzy logic with decision trees. Nodes represent fuzzy sets; edges represent fuzzy conditions rather than exact thresholds. Handles uncertainty in classification problems.
  • Advantage over crisp logic: More closely models human reasoning — temperature "slightly above normal" rather than "above 25.0°C".

EXAMPLEFuzzy Climate Prediction: "IF temperature is HIGH AND humidity is LOW, THEN weather is SUNNY (70% certainty)." Output is a probability, not a binary decision.

Fuzzy logic is essential in control systems (HVAC, washing machines, anti-lock brakes) where exact numerical thresholds fail to model real-world imprecision.

Stochastic Search — Genetic Algorithms + Simulated Annealing APPEARED 2024-25
A · Conceptual

Stochastic search methods use probabilistic approaches to explore optimization solution spaces, avoiding local optima through randomness.

B · Exam Format

1. GENETIC ALGORITHMS (GAs):

Genetic Algorithms are search heuristics inspired by natural selection that find approximate solutions to optimization problems through population evolution.
  • Population: Set of candidate solutions (chromosomes — binary strings or permutations).
  • Fitness Function: Evaluates solution quality — higher fitness = better solution.
  • Selection: Individuals chosen based on fitness (Roulette Wheel or Tournament).
  • Crossover: Two parent chromosomes exchange parts at crossover points → offspring.
  • Mutation: Small random changes in offspring — maintains diversity, prevents premature convergence.
  • Repeat for multiple generations until termination condition (max generations or fitness threshold).

★ NEW: 2. SIMULATED ANNEALING (SA):

Simulated Annealing is a probabilistic optimization technique that mimics metallurgical annealing — heating and slow cooling removes defects, guiding the system to a global minimum.
  • Temperature Parameter: Initially high — the algorithm accepts worse solutions with high probability (explores widely). Decreases gradually — acceptance probability decreases.
  • Acceptance Probability: P(accept worse solution) = exp(−ΔE/T). When T is high, bad moves accepted freely; as T→0, only improvements accepted.
  • Neighborhood Search: At each step, randomly explores neighboring solutions (small random mutation of current).
  • Cooling Schedule: Gradual reduction of T — linear, geometric, or logarithmic decay.
  • Advantage over GA: Simpler implementation; single solution vs population; good for continuous optimization.
Aspect Genetic Algorithm Simulated Annealing

EXAMPLERoute optimization: GA evolves population of routes through crossover/mutation. SA starts with one route, randomly modifies it, accepts worse routes at high temperature to escape local optima, converges to optimal as temperature drops.

Stochastic methods are essential for NP-hard optimization problems (TSP, scheduling, neural architecture search) where exhaustive search is computationally infeasible.

FILTERING STREAMS — 3 TYPES:

  • Content-based Filtering: Filter by attributes/content — e.g., only tweets containing #election hashtag.
  • Time-based Filtering: Filter within specific time range — e.g., log entries in last 24 hours only.
  • Probabilistic Filtering (Bloom Filter): Bit array + k hash functions — tests membership efficiently. False positives possible, false negatives impossible.

COUNTING DISTINCT ELEMENTS:

  • Challenge: High volume makes storing all elements impractical.
  • Hashing: Hash elements to reduce memory usage.
  • HyperLogLog Algorithm: Probabilistic data structure estimating cardinality (count of distinct elements) using minimal memory — O(log log n) space. Example: Count unique IP addresses in network traffic without storing all IPs.

ESTIMATING MOMENTS (AMS Algorithm):

  • First Moment: Sum of all elements in stream.
  • Second Moment: Sum of squares — used to measure variance/distribution spread.
  • AMS (Alon-Matias-Szegedy) Algorithm: Estimates frequency moments using random variables and sketches — O(log n) space instead of O(n). Used for variance estimation in financial data streams.

COUNTING ONES IN A WINDOW + DECAYING WINDOW:

  • Counting Ones: Track number of 1s (specific events) in a fixed-size sliding window. Sliding window updates counts as new data arrives. Example: Count "likes" in last 5 minutes on live video stream.
  • Decaying Window: Assigns exponentially decreasing weight to older data: weight = e^(−λt) where t = age of data, λ = decay rate. Recent events count more. Advantage: Keeps analytics relevant to current trends. Example: CPU usage monitoring — weight recent data 10× more than data from 1 hour ago.

Mining Frequent Itemsets — Support · Confidence · Lift · Apriori APPEARED 2024-25
B · Exam Format
The Apriori Algorithm identifies frequent itemsets and generates association rules from transactional databases using iterative candidate generation with anti-monotonicity pruning.

THREE KEY MEASURES:

  • Support(X): count(X) / total transactions. Measures frequency of itemset X in the database.
  • Confidence(X→Y): Support(X∪Y) / Support(X). Probability that Y is bought given X is bought.
  • Lift(X→Y): Confidence(X→Y) / Support(Y). Measures how much more likely X→Y is than random chance. Lift > 1 = positive association.

APRIORI STEPS (with worked example):

Transactions: T1:{Bread,Milk}, T2:{Bread,Diaper,Beer}, T3:{Milk,Diaper,Beer}, T4:{Bread,Milk,Diaper}. Min Support = 50%.

  • Generate 1-item frequent sets: Count each item. {Bread}=3, {Milk}=3, {Diaper}=3, {Beer}=2. All meet min support ≥ 2/4 = 50%.
  • Generate 2-item candidates: All pairs of frequent 1-itemsets: {Bread,Milk}, {Bread,Diaper}, {Milk,Diaper}, {Bread,Beer}, {Milk,Beer}, {Diaper,Beer}.
  • Count and prune: {Bread,Milk}=2✓, {Bread,Diaper}=2✓, {Milk,Diaper}=2✓, {Diaper,Beer}=2✓. Prune: {Bread,Beer}=1✗, {Milk,Beer}=1✗.
  • Generate 3-item candidates: Combine remaining 2-item sets → {Bread,Milk,Diaper}=1 → pruned.
  • Anti-monotonicity pruning: If {Milk,Beer} is infrequent, ALL supersets like {Bread,Milk,Beer} are pruned without counting.
  • Generate rules: From {Diaper,Beer}: Diaper→Beer: Confidence = 2/3 = 67%. Beer→Diaper: Confidence = 2/2 = 100%.
Apriori's anti-monotonicity property is its key efficiency mechanism — it dramatically reduces the candidate search space without missing any frequent itemset.

1. HIERARCHICAL CLUSTERING:

Hierarchical clustering creates a tree-like dendrogram by iteratively merging (agglomerative) or splitting (divisive) clusters based on inter-cluster distance.
  • Agglomerative (AGNES — Bottom-Up): Start each point as its own cluster → merge closest pairs → repeat until one cluster. Most commonly used.
  • Divisive (DIANA — Top-Down): Start with one cluster → split recursively. More computationally expensive.

LINKAGE METHODS (how inter-cluster distance is measured):

Linkage Distance Measure Effect
Single Linkage Nearest points in two clusters Can create chain-like elongated clusters
Complete Linkage Farthest points in two clusters Creates compact, tight clusters
Average Linkage Average distance between all point pairs Balanced — most commonly used in practice

2. K-MEANS CLUSTERING (Steps):

  • Choose K (number of clusters). Initialize K random centroids.
  • Assign each data point to nearest centroid (Euclidean distance).
  • Recalculate centroids as mean of all assigned points.
  • Repeat steps 2–3 until centroids stabilize (convergence).

Limitations: Requires K specified in advance; assumes spherical clusters; sensitive to initial centroid placement.

MapReduce — Numerical Example 10 marks · 2024-25
B · Exam Format
MapReduce is a programming model for processing large datasets in parallel by dividing computation into Map tasks (data transformation) and Reduce tasks (aggregation) across a commodity cluster.

STEPS WITH NUMERICAL EXAMPLE (Sum of [1, 2, 3, 4]):

  • Input Split: Large dataset divided into smaller chunks — each processed independently by a mapper.
  • Map Phase: Each mapper processes a chunk and emits (key, value) pairs. Input: [1,2,3,4] → Map emits: (1,1),(2,1),(3,1),(4,1).
  • Shuffle and Sort: Framework groups all values with same key and distributes to reducers.
  • Reduce Phase: Reducer sums values per key. Result: (1,4) — sum of all numbers = 4. For Word Count: Reducer sums all (word, 1) pairs per word.
  • Output: Final aggregated result written to HDFS or output storage.
  • Advantages: Scalable (adds more nodes), Parallel (processes simultaneously), Fault Tolerant (failed tasks retried).
  • Applications: Word count, log processing, sorting, distributed ML (k-means clustering).

Hadoop is an open-source distributed framework for storing and processing massive datasets across commodity computer clusters in a scalable, fault-tolerant manner.

MAC (Medium Access Control) Protocol in IoT governs how sensor nodes share the wireless channel, balancing energy efficiency, collision avoidance, and latency for battery-constrained devices.

★ Sensor Deployment + Node Discovery Appeared Both Years · 10m
B · Exam Format
Sensor Node Deployment refers to strategies for physically placing sensor nodes in an environment to achieve desired coverage, connectivity, and energy efficiency for the target application.

DEPLOYMENT TECHNIQUES (3 Types):

  • Random Deployment: Nodes dropped randomly (e.g., by aircraft over hazardous terrain). Low cost, easy but uneven coverage — some areas may be over-covered, others missed. Used: Battlefield monitoring, disaster response.
  • Deterministic Deployment: Nodes placed at pre-calculated optimal positions (grid, hexagonal, or custom layout). Maximizes coverage uniformity and minimizes overlaps. Used: Smart agriculture, building automation.
  • Self-Deployment / Mobile Sensors: Nodes move autonomously to fill coverage gaps using actuators (wheels, thrusters). Self-organizing — adjusts to changing environment. Used: Underwater sensing, robotic exploration.

NODE DISCOVERY TECHNIQUES:

  • Flooding-based Discovery: New node broadcasts a HELLO message. Neighbors respond with their IDs and capabilities. Simple but creates broadcast storm in dense networks.
  • Beacon-based Discovery: Base stations/anchor nodes periodically broadcast beacon signals. New nodes listen for beacons to identify neighbors and network structure. Low overhead for the new node.
  • Anchor-based Discovery: Pre-deployed anchor nodes (with known GPS positions) broadcast their coordinates. New nodes calculate their own position relative to anchors for localization + discovery.

Why important: Without proper deployment and discovery, WSNs have coverage holes (missed events) or connectivity gaps (isolated nodes unable to relay data to the sink).

Routing Protocols — LEACH · Directed Diffusion · AODV + Data Aggregation Appeared Both Years
B · Exam Format

ROUTING PROTOCOLS:

  • LEACH (Low-Energy Adaptive Clustering Hierarchy): Cluster-based protocol. Randomly elects cluster heads each round — distributes energy load. Cluster members send data to cluster head → cluster head aggregates and forwards to sink. Extends network lifetime by preventing premature death of specific nodes.
  • Directed Diffusion: Data-centric protocol. Sink broadcasts "interest" messages describing desired data. Sources set up gradients toward sink. Data flows along reinforced paths (highest quality path). Eliminates centralized control.
  • AODV (Ad-hoc On-demand Distance Vector): On-demand routing — discovers route only when needed (vs proactive protocols that maintain routing tables). Reduces overhead in sparse/dynamic networks. Route Request (RREQ) flooded, Route Reply (RREP) returns along reverse path.

DATA AGGREGATION AND DISSEMINATION:

Data Aggregation is the process of combining multiple sensor readings at an intermediate node (cluster head) before forwarding to sink — reducing redundant transmissions and saving energy.
  • Why needed: Multiple nearby sensors often measure similar values. Sending all readings individually wastes bandwidth and energy.
  • Methods: MIN/MAX (send only extreme value), AVERAGE (send mean of all readings), SUM (for counting applications), TEMPORAL aggregation (combine readings over time window).
  • Dissemination: Controlled distribution of data or queries from sink to relevant nodes — opposite of aggregation. Used to distribute software updates, configuration changes to specific nodes.

EXAMPLE10 temperature sensors in a factory report to cluster head: 32, 33, 31, 33, 32, 32, 31, 33, 32, 32°C. Cluster head sends ONE aggregated value (mean = 32.1°C) instead of 10 separate packets — 90% bandwidth reduction.

B · Exam Format
MQTT (Message Queuing Telemetry Transport) is a lightweight publish-subscribe messaging protocol designed for IoT devices on bandwidth-constrained networks, using a central broker to route messages between publishers and subscribers.
  • Publisher: IoT device that produces and publishes data to a named topic ("home/bedroom/temperature").

  • Subscriber: Client (app, server) that subscribes to topics and receives all matching messages.

Types of Learning + Well-Defined Learning Problem
B · Exam Format
Machine Learning is a branch of AI that enables systems to automatically learn and improve from experience without being explicitly programmed, by building statistical models from data.

  • Reinforcement Learning: Agent learns by interacting with environment → receives rewards/penalties → maximizes cumulative reward.
  • Data Science vs ML: DS = broader field (data collection, cleaning, analysis, communication + ML). ML = the modeling/algorithm component within DS pipeline.
★ Concept Learning + Find-S Algorithm 10 marks · 2024-25
B · Exam Format
Concept Learning is the task of inferring a boolean-valued function from labeled examples by searching a hypothesis space for the most consistent hypothesis.
  • Find-S Algorithm: Starts with most specific hypothesis h=⟨∅,∅,...,∅⟩. For each POSITIVE example: generalize h minimally to cover the example. Ignores negative examples. Outputs most specific consistent hypothesis.
  • Candidate Elimination: Maintains both G (most general) and S (most specific) boundary sets. Positive examples specialize G; negative examples generalize S. Outputs complete version space.
  • Limitation of Find-S: Ignores negative examples; cannot detect inconsistent data; outputs only one hypothesis.

EXAMPLELearning "Enjoy Sport": After positive examples (Sunny,Warm,Normal,Strong) and negative (Overcast,Cold,High,Weak), Find-S outputs ⟨Sunny,Warm,?,Strong,?,?⟩.

LOGISTIC REGRESSION FOR CLASSIFICATION:

  • Yes — used for binary classification: Applies sigmoid σ(z) = 1/(1+e⁻ᶻ) to linear output → probability output (0–1). If P ≥ 0.5 → Class 1; else → Class 0.
  • Decision Boundary: Hyperplane where P=0.5 (z=0) — linear boundary in feature space.

NAÏVE BAYES CLASSIFIER:

Naïve Bayes is a probabilistic classifier that applies Bayes' theorem with the conditional independence assumption: P(Class|features) ∝ P(Class) × ∏P(featureᵢ|Class).
  • Prior: P(Class) — initial class probability from training data.
  • Likelihood: P(featureᵢ|Class) — probability of feature given class.
  • Posterior: P(Class|features) — updated probability → pick class with highest posterior.
  • Naïve Assumption: All features independent given class label — mathematically wrong but works well in practice for text.
  • EM Algorithm: Handles missing data — E-step (estimate hidden variable values), M-step (maximize parameters) → repeat until convergence.

SVM — KEY POINTS:

  • Hyperplane: w·x + b = 0. Maximum margin = 2/‖w‖. Support vectors define the hyperplane.
  • Kernels: Linear K=xᵢ·xⱼ, Polynomial K=(xᵢ·xⱼ+c)ᵈ, RBF/Gaussian K=exp(−γ‖xᵢ−xⱼ‖²).
  • Soft Margin: Slack variables ξᵢ allow misclassification. C parameter trades margin width vs error tolerance.

ID3 Algorithm + k-NN + Clustering vs Decision Tree
B · Exam Format

ID3 ALGORITHM:

ID3 (Iterative Dichotomiser 3) constructs a decision tree by recursively selecting the attribute with highest Information Gain as the splitting criterion.
  • Entropy: H(S) = −∑pᵢlog₂pᵢ. H=0 means pure set; H=1 means 50-50 split.
  • Information Gain: IG(S,A) = H(S) − ∑(|Sᵥ|/|S|)·H(Sᵥ). Select attribute with max IG.
  • Algorithm: If all same class → leaf. Else: compute IG for all attributes → split on max IG → recurse → until pure or no attributes.
  • Overfitting: Perfectly fit training data → fails on new. Fix: pruning (pre = early stop, post = trim grown tree).
  • Inductive Bias: Prefers shorter trees, high IG near root.

k-NN (INSTANCE-BASED LEARNING):

  • Lazy learning: No training model — entire training set memorized. Classification = majority vote of k nearest neighbors.
  • Distance metrics: Euclidean √∑(xᵢ−yᵢ)², Manhattan ∑|xᵢ−yᵢ|, Hamming (categorical).
  • Small k: High variance (overfitting). Large k: High bias (underfitting). Use cross-validation to find optimal k.

ANN + Backpropagation + Gradient Descent Types + Delta Rule + CNN
B · Exam Format
ANN (Artificial Neural Network) is a computational model of interconnected layers of neurons that learns nonlinear input-output mappings by adjusting synaptic weights through training.
  • Architecture: Input layer → Hidden layers (learn features) → Output layer. Activation functions (Sigmoid, tanh, ReLU) introduce non-linearity.
  • Backpropagation Steps: (1) Forward pass → compute output. (2) Compute loss (MSE, cross-entropy). (3) Backward pass using chain rule → compute ∂L/∂w for each weight. (4) Update: w ← w − η·(∂L/∂w). (5) Repeat for epochs until convergence.

Q-Learning · 3 RL Models · Genetic Algorithm
B · Exam Format
Reinforcement Learning is a paradigm where an agent maximizes cumulative reward through sequential actions in an environment, guided by feedback in the form of rewards and penalties — no supervisor.
  • MDP Components: States (S), Actions (A), Transition T(S'|S,A), Reward R(S,A), Discount γ. Markov property: future depends only on current state.
  • Q-Learning Update: Q(S,A) ← Q(S,A) + α[R + γ·maxQ(S',A') − Q(S,A)]. α=learning rate, γ=discount factor, R=immediate reward.
  • ε-Greedy Policy: Explore (random action) with prob ε; exploit (best known action) with prob 1−ε.
  • Deep Q-Learning: Q-table → Neural Network (Q-network). Handles high-dimensional state spaces (game pixels). Uses experience replay for stability.

GENETIC ALGORITHM — 6 STEPS:

  • Initialization: Generate N random candidate solutions (chromosomes).
  • Evaluation: Compute fitness function for each individual.
  • Selection: Choose parents by fitness — Roulette Wheel or Tournament selection.
  • Crossover: Exchange chromosome segments between two parents → produce offspring.
  • Mutation: Randomly flip bits in offspring with low probability — prevents premature convergence.
  • Replacement → Repeat: New generation replaces old. Repeat until termination criterion met.
