Data Analytics Lifecycle — 6 Phases
B · Exam Answer Format
The Data Analytics Lifecycle is a structured, iterative six-phase framework that guides an analytics project from initial problem identification through model deployment and performance monitoring.
  • Phase 1 — Discovery: Define business problem, frame hypotheses, identify data sources, assess resources. Deliverable: Project charter.
  • Phase 2 — Data Preparation: ETL operations — extract, clean, normalize, handle missing values in an analytic sandbox.
  • Phase 3 — Model Planning: Select algorithms and tools based on variable relationships and objective type (regression/classification/clustering).
  • Phase 4 — Model Building: Develop and train model on training data; validate on test data; evaluate with precision, recall, AUC.
  • Phase 5 — Communicate Results: Translate outputs into business insight using visualizations and dashboards; determine if goals were met.
  • Phase 6 — Operationalization: Deploy model into production pipeline; monitor performance; iterate as new data arrives.
The lifecycle is iterative — poor model performance triggers a return to data preparation, not a restart from discovery.

★ NEW: Big Data — Characteristics (5 V's) APPEARED 2024-25
A · Conceptual Understanding

Big Data refers to datasets so large, fast-moving, or diverse that traditional data processing tools cannot handle them. Characterized by the 5 V's:

  • Volume: Massive scale — terabytes to petabytes generated daily (Facebook: 4 petabytes/day).
  • Velocity: Speed of data generation and required processing — real-time (stock feeds, IoT sensors).
  • Variety: Multiple formats — structured (SQL), semi-structured (JSON), unstructured (video, text).
  • Veracity: Trustworthiness and accuracy of data — noisy, incomplete, inconsistent data reduces analytical value.
  • Value: The ultimate goal — converting raw Big Data into actionable business insights through analytics.

Sources of Big Data: Social media, IoT sensors, e-commerce transactions, scientific instruments, mobile devices, log files, healthcare records.

B · Exam Answer Format
Big Data refers to extremely large, high-velocity, and heterogeneous datasets that exceed the processing capability of conventional database tools, characterized by the five dimensions: Volume, Velocity, Variety, Veracity, and Value.
  • Volume: Scale of data generated — ranges from terabytes to zettabytes; requires distributed storage (HDFS, S3).
  • Velocity: Rate of data generation; real-time analytics platforms (RTAP) process incoming streams within milliseconds.
  • Variety: Structural heterogeneity — 80% of enterprise data is unstructured, requiring specialized processing pipelines.
  • Veracity: Data quality and reliability — poor veracity leads to incorrect analytical conclusions despite large volume.
  • Value: ROI of analytics — data has no inherent value; value is extracted through analysis, modeling, and decision support.

EXAMPLE Twitter generates 500 million tweets/day (Volume + Velocity). Tweets contain text, images, videos (Variety). Spam and fake accounts reduce Veracity. Sentiment analysis extracts Value for brand monitoring.

Big Data platforms like Hadoop were specifically engineered to address the 5 V challenges that traditional RDBMS systems cannot handle at scale.

PCA — Principal Component Analysis 10 marks · 2024-25
A · Conceptual Understanding

PCA is a dimensionality reduction technique. When data has many features (high-dimensional), PCA finds a new set of axes (principal components) that capture the maximum variance in the data, allowing you to discard low-variance dimensions without losing much information.

Step-by-step process:

  • Standardize the data (zero mean, unit variance).
  • Compute the covariance matrix to find how features relate to each other.
  • Compute eigenvectors and eigenvalues of the covariance matrix. Eigenvectors = directions of maximum variance (principal components). Eigenvalues = magnitude of variance in that direction.
  • Sort eigenvectors by eigenvalue in descending order.
  • Select top k eigenvectors (those explaining 95%+ of total variance).
  • Project original data onto these k components — reduced dataset.
ANALOGY Photographing a 3D object in 2D: You choose the angle that captures the most information. PCA finds that angle mathematically — the direction that "shows the most" in the data.
B · Exam Answer Format
Principal Component Analysis (PCA) is an unsupervised dimensionality reduction technique that transforms high-dimensional data into a lower-dimensional space by identifying orthogonal axes (principal components) along which variance is maximized.
  • Covariance Matrix: Captures the pairwise feature correlations — basis for computing the directions of maximum spread.
  • Eigenvectors/Eigenvalues: Eigenvectors define the principal component directions; eigenvalues quantify the variance explained — used to rank components.
  • Variance Explained: Select fewest components whose cumulative eigenvalue sum exceeds 95% of total variance.
  • Applications: Feature reduction before SVM/ANN training, image compression, noise removal, visualization of high-dimensional data.

EXAMPLE A dataset with 50 gene expression features is reduced to 5 principal components (explaining 97% variance) before classification, reducing training time by 90%.

PCA is widely used as a preprocessing step to reduce overfitting, improve computational efficiency, and enable visualization of datasets with hundreds of features.

★ NEW: Stochastic Search Methods 2024-25 Sec A
B · Exam Answer Format (2-mark answer)
Stochastic Search Methods are optimization algorithms that use randomness to explore search spaces, avoiding local optima by probabilistically accepting non-optimal moves during the search process.
  • Simulated Annealing: Inspired by metallurgical annealing — accepts worse solutions with decreasing probability (temperature parameter), enabling escape from local optima.
  • Genetic Algorithms: Evolutionary stochastic search using selection, crossover, and mutation — searches multiple points simultaneously.
  • Applications in Data Analytics: Feature selection, hyperparameter optimization, neural network weight initialization, combinatorial optimization problems.
Unlike deterministic methods, stochastic search sacrifices guaranteed optimality for practical tractability in complex, high-dimensional search spaces.

★ NEW: RTAP + Real-Time Sentiment Analysis Case Study 10 marks · 2024-25
A · Conceptual Understanding

RTAP (Real-Time Analytics Platform) is a system architecture designed to process, analyze, and act on data streams as they arrive — with processing latency in milliseconds to seconds.

RTAP Architecture Components:

  • Data Ingestion Layer: Collects streaming data from sources (Twitter API, IoT sensors, financial feeds). Tools: Apache Kafka, Flume.
  • Stream Processing Layer: Real-time computation engine. Tools: Apache Storm, Apache Spark Streaming, Flink.
  • Analytics Layer: Applies ML models and statistical algorithms to each micro-batch or event.
  • Storage Layer: Results stored in low-latency databases (HBase, Redis, Cassandra).
  • Visualization Layer: Real-time dashboards (Grafana, Kibana) presenting live metrics.

Real-Time Sentiment Analysis Case Study:

  • Collect tweets via Twitter Streaming API filtered by keyword (e.g., product name).
  • Ingest tweet stream into Kafka topic.
  • Spark Streaming processes 500ms micro-batches — tokenizes text, removes stopwords.
  • Pre-trained Naïve Bayes classifier assigns Positive/Negative/Neutral sentiment to each tweet.
  • Sentiment counts aggregated using sliding window (last 1 hour).
  • Results pushed to dashboard showing live sentiment trend — brands act on sudden spikes.
B · Exam Answer Format
Real-Time Analytics Platform (RTAP) is a distributed computing architecture that ingests, processes, and analyzes continuous data streams with sub-second latency, enabling immediate decision-making on live data.
  • Architecture: Five-layer stack — Ingestion (Kafka) → Processing (Spark Streaming/Storm) → Analytics (ML models) → Storage (HBase) → Visualization (Grafana).
  • Micro-batching: Spark Streaming processes data in small time windows (500ms–1s), balancing latency and throughput.
  • Sentiment Analysis: Text classification applied to tweet streams — Naïve Bayes or LSTM assigns sentiment labels in real-time.
  • Sliding Window: Counts computed over the last N minutes rather than all historical data, ensuring recency of insights.

CASE STUDY During a product launch, a brand monitors 50,000 tweets/minute via RTAP. A sudden 40% negative spike at 3PM is detected in real-time, triggering an immediate PR response — possible only with streaming analytics.

RTAP transforms reactive business decisions into proactive responses by compressing the time between data generation and insight delivery from hours to milliseconds.

★ NEW: Filtering Stream — Benefits & Limitations 10 marks · 2024-25
A · Conceptual Understanding

Filtering Streams is the process of determining, in real-time, whether each arriving stream element belongs to a predefined set S — without storing all of S in memory.

Bloom Filter — The Primary Technique: Uses a bit array of size m and k hash functions. For membership check: hash the element with all k functions; if all k bits are 1 → element is probably in S. If any bit is 0 → element is definitely NOT in S.

B · Exam Answer Format
Stream Filtering is a real-time stream processing technique that tests element membership in a reference set using memory-efficient probabilistic data structures like Bloom Filters.

BENEFITS:

  • Space Efficiency: Bloom Filter requires O(m) bits (m ≪ |S|×pointer size) — enables filtering million-element sets with kilobytes of memory.
  • Speed: O(k) time per element — constant-time lookup regardless of set size; suitable for high-velocity streams.
  • No False Negatives: If a Bloom Filter says "not in set", the element is guaranteed to be absent — safe for spam/fraud rejection.

LIMITATIONS:

  • False Positives: May incorrectly report an absent element as present — probability controlled by m and k but never eliminated.
  • No Deletion: Standard Bloom Filters cannot remove elements — Counting Bloom Filters address this at higher memory cost.
  • Hash Dependency: Quality depends on hash function uniformity — poor hash functions inflate false positive rate.
Bloom Filters are used in Google Chrome (malicious URL detection), Apache Cassandra (SSTables), and spam filtering systems where probabilistic filtering at scale is required.

★ NEW: CLIQUE vs ProCLUS — Subspace Clustering 10 marks · 2024-25
A · Conceptual Understanding

Both address clustering high-dimensional data where traditional K-means fails due to the curse of dimensionality — in high dimensions, all points appear equally distant.

CLIQUE (Clustering In QUEst): Grid-based density algorithm. Divides each dimension into equal-width intervals (grid cells). A cell is dense if it contains more than τ points. Finds dense cells in subspaces of increasing dimensionality. Produces axis-aligned clusters in subspaces.

ProCLUS (Projected CLUStering): Medoid-based projected clustering. Starts with k medoids; for each medoid, finds the subset of dimensions (subspace) where its cluster is most compact. Assigns points to clusters in their relevant subspace.

B · Exam Answer Format — CLIQUE vs ProCLUS
Subspace clustering algorithms identify clusters in relevant subsets of dimensions, addressing the curse of dimensionality where full-dimensional distance metrics lose meaning in high-dimensional spaces.
Aspect CLIQUE ProCLUS
Approach Grid-based density Medoid-based projected
Cluster Shape Axis-aligned rectangles Arbitrary projected shapes
Subspace Same subspace for entire cluster Different subspace per cluster
Scalability Scales with grid resolution Requires k (num clusters)
Best for Dense region detection Flexible cluster shapes
Subspace clustering is critical in genomics, image analysis, and text mining where data has hundreds of features but each cluster is relevant in only a few dimensions.

★ NEW: Market-Based Modelling 10 marks · 2024-25
B · Exam Answer Format
Market-Based Modelling (Market Basket Analysis) is a data mining technique that analyzes large transaction databases to discover purchase associations between products, enabling product placement, promotions, and recommendation strategies.
  • Transaction Representation: Each shopping basket = a set of items purchased together; the entire database = a matrix of items × transactions (0/1).
  • Boolean Matrix Model: Rows = customers/transactions, Columns = items, Cell = 1 if item purchased. Frequent itemsets = columns with high co-occurrence.
  • Association Rules: If {A,B} → {C} with support=30%, confidence=75%, then 30% of all transactions contain A,B,C; 75% of people buying A and B also buy C.
  • Applications: Retail shelf placement (complementary items together), cross-selling recommendations ("customers also bought"), promotional bundling.

EXAMPLE Amazon's "Frequently Bought Together": Association rule {phone} → {phone case} (confidence=82%) is discovered from purchase history, enabling the bundling recommendation on product pages.

Market-based modelling is the analytical backbone of recommendation engines in e-commerce, generating significant incremental revenue through data-driven cross-sell strategies.

MapReduce + Hive + Pig + HBase — Combined Answer
B · Exam Answer (all 4 in one 10-mark answer)
The Hadoop ecosystem provides a suite of tools — MapReduce (computation), Hive (querying), Pig (scripting), and HBase (NoSQL storage) — forming a complete Big Data processing stack.
  • MapReduce: Parallel processing model — Map phase transforms input into (key,value) pairs; Reduce phase aggregates values per key. Example: Word count — Map emits (word,1); Reduce sums per word.
  • Hive: Data warehouse layer on HDFS — translates HiveQL (SQL-like queries) into MapReduce jobs. Best for batch analytical queries on large static datasets.
  • Pig: High-level dataflow scripting using Pig Latin. Translates ETL scripts to MapReduce. Best for complex data transformation pipelines (JOIN, GROUP, FILTER operations).
  • HBase: Column-family NoSQL database on HDFS — provides random read/write access that HDFS lacks. Stores billions of rows × millions of columns. Used for real-time lookup alongside batch Hadoop jobs.
Together, these tools form a complete analytics pipeline: Pig for ETL, Hive for querying, HBase for real-time access, all built on MapReduce's distributed computation engine.

★ NEW: NoSQL vs SQL + 4 Types of NoSQL 10 marks · 2024-25
B · Exam Answer Format
NoSQL databases are non-relational data stores designed for horizontal scalability, flexible schemas, and high-volume distributed data management — addressing limitations of traditional SQL databases in Big Data contexts.
Attribute SQL (Relational) NoSQL
Schema Fixed, predefined Dynamic, flexible
Scalability Vertical (bigger server) Horizontal (add nodes)
Query Language SQL (standardized) Varies per system
ACID Full ACID compliance BASE (eventual consistency)
Best for Structured, relational data Unstructured, high-volume data
  • Key-Value Store: Simplest form — Redis, DynamoDB. Data stored as key → value pairs. Extremely fast. Use case: session management, caching.
  • Column-Family Store: HBase, Cassandra. Data in rows with dynamic columns grouped into families. Use case: IoT time-series, social media analytics.
  • Document Store: MongoDB, CouchDB. Stores JSON/BSON documents — flexible nested structure. Use case: content management, catalogs.
  • Graph Database: Neo4j. Stores nodes + edges + properties. Use case: social networks, fraud detection, recommendation engines.
NoSQL databases power the world's largest web applications — Facebook (Cassandra), Google (Bigtable), Amazon (DynamoDB) — where SQL cannot scale to required volumes.

IoT Architecture + M2M — Core Answer
B · Exam Answer Format
Internet of Things (IoT) is a network of physical objects embedded with sensors, software, and connectivity that enables autonomous data collection, exchange, and actuation without direct human interaction.

  • Design Principles: Interoperability, scalability, security by design, energy efficiency, standardized communication protocols.
IoT creates a digital nervous system for the physical world — enabling environments to sense, communicate, and respond intelligently without human intervention.

★ NEW: NFC Technology 10 marks · 2024-25
A · Conceptual Understanding

NFC (Near Field Communication) is a short-range (≤4cm) wireless communication standard based on RFID principles, operating at 13.56 MHz. Unlike RFID, NFC devices can operate as both reader AND tag (bidirectional).

NFC Operating Modes:

  • Card Emulation: NFC device acts as a contactless smart card (e.g., smartphone used as transit card).
  • Reader/Writer: NFC device reads/writes NFC tags embedded in objects (e.g., reading a museum exhibit tag).
  • Peer-to-Peer: Two NFC devices exchange data directly (e.g., Android Beam file transfer).
B · Exam Answer Format
NFC (Near Field Communication) is a set of communication protocols enabling short-range (≤4cm) wireless data exchange between compatible devices at 13.56 MHz, extending RFID with peer-to-peer capability.
  • NFC vs RFID: RFID is unidirectional (reader reads tag); NFC is bidirectional (both devices can read/write). NFC requires proximity (≤4cm) vs RFID's longer range.
  • Three Modes: Card Emulation (acts as smart card), Reader/Writer (reads NFC tags), Peer-to-Peer (device-to-device exchange).
  • Security: Short range provides inherent security — eavesdropping requires proximity. Combined with encryption for payment security.
  • Applications: Contactless payments (Google Pay, Apple Pay), transit cards, access control, asset tagging, data sharing between smartphones.
NFC bridges the physical and digital world at the point of human interaction — a 4cm tap initiating authentication, payment, or data transfer in under 100ms.

★ NEW: 6LoWPAN 2023-24 Sec A · 2 marks
B · 2-mark Answer
6LoWPAN (IPv6 over Low-power Wireless Personal Area Networks) is an adaptation layer that enables IPv6 packets to be transmitted over IEEE 802.15.4 low-power wireless networks used in IoT sensor nodes.
  • Problem solved: Standard IPv6 packets (1280 bytes) are too large for IEEE 802.15.4 frames (127 bytes) — 6LoWPAN compresses IPv6 headers and fragments packets.
  • Importance: Allows every IoT sensor node to have a globally routable IPv6 address — enabling true internet connectivity for resource-constrained devices.
  • Applications: Smart metering, industrial WSN, smart grid, connected healthcare devices.

★ NEW: MQTT Protocol 10 marks · 2023-24
A · Conceptual Understanding

MQTT (Message Queuing Telemetry Transport) is a lightweight publish-subscribe messaging protocol designed for constrained IoT devices on low-bandwidth, high-latency networks. Runs over TCP/IP.

Publish-Subscribe Model:

  • Publisher: IoT device that produces data and publishes it to a topic (e.g., "home/bedroom/temperature").
  • Broker: Central server (e.g., Mosquitto, AWS IoT) that receives messages from publishers and routes them to subscribers.
  • Subscriber: Client (app, server) that subscribes to a topic and receives all messages published to it.

QoS Levels: 0 (at most once — fire and forget), 1 (at least once — acknowledged), 2 (exactly once — two-phase handshake).

B · Exam Answer Format
MQTT (Message Queuing Telemetry Transport) is a lightweight publish-subscribe messaging protocol designed for IoT applications on bandwidth-constrained, unreliable networks, using a central broker to route messages between publishers and subscribers.
  • Architecture: Three components — Publisher (sensor/device), Broker (message router), Subscriber (application) — fully decoupled; publisher and subscriber never interact directly.
  • Topics: Hierarchical path-based routing (e.g., "factory/line1/motor/temp") — subscribers use wildcards (+, #) for flexible topic subscriptions.
  • QoS Levels: 0 (best effort), 1 (guaranteed delivery, possible duplicates), 2 (guaranteed exactly-once delivery).
  • Advantages over HTTP: Binary protocol (vs text-based HTTP); persistent connection; broker handles reliability; far lower overhead for thousands of devices.

EXAMPLE Smart home: Temperature sensor publishes to "home/living/temp" every 30s → Mosquitto broker → Home automation app subscribed to "home/#" receives all home sensor readings automatically.

MQTT is the de facto IoT messaging protocol — used by AWS IoT, Azure IoT Hub, Facebook Messenger, and industrial SCADA systems due to its extreme efficiency on constrained networks.

★ NEW: Logistic Regression for Classification 2024-25 Sec A
B · Exam Answer
Logistic Regression is a supervised learning algorithm used for binary classification that applies a sigmoid function to linear regression output, producing a probability between 0 and 1 for class membership.
  • Yes — used for classification: Despite the name "regression", it classifies by thresholding probability. If P(Y=1|X) ≥ 0.5 → Class 1; else → Class 0.
  • Sigmoid Function: σ(z) = 1/(1+e⁻ᶻ) where z = β₀ + β₁X. Maps any real value to (0,1) — interpreted as probability.
  • Decision Boundary: The hyperplane where P = 0.5 (z=0) — linear boundary in feature space.
  • Training: Parameters estimated by maximizing log-likelihood (not minimizing squared error).

EXAMPLE Email spam detection: X = word frequencies, Y = spam(1)/not-spam(0). Logistic regression outputs P(spam|email) — if ≥0.5, flag as spam.

★ NEW: Concept Learning + Find-S Algorithm 10 marks · 2024-25
A · Conceptual Understanding

Concept Learning is the task of inferring a boolean-valued function from training examples. The "concept" is a subset of instances — the learner must determine which instances belong to the target concept.

Find-S Algorithm: Finds the most specific hypothesis consistent with all positive training examples.

  • Initialize h to the most specific hypothesis: h = ⟨∅, ∅, ..., ∅⟩ (no instance satisfies it).
  • For each positive training example d: For each attribute aᵢ — if aᵢ in h is satisfied by d, do nothing; else replace aᵢ with the next more general constraint.
  • Ignore negative examples.
  • Output the final hypothesis h.

Candidate Elimination Algorithm: Maintains both S (most specific boundary) and G (most general boundary) of the version space. Positive examples narrow G; negative examples narrow S. Outputs the complete version space.

B · Exam Answer Format
Concept Learning is the task of learning a boolean target function from labeled training examples by searching a hypothesis space for a hypothesis consistent with all positive examples and no negative examples.
  • Hypothesis Space: All possible hypotheses over instance attributes — Find-S searches this space from specific to general.
  • Find-S: Begins with the most specific hypothesis (null); for each positive example, generalizes minimally to include it. Final output: most specific consistent hypothesis.
  • Limitation of Find-S: Ignores negative examples; cannot detect inconsistent data; outputs one hypothesis not the complete version space.
  • Candidate Elimination: Maintains complete description of all consistent hypotheses via G (general) and S (specific) boundary sets.

EXAMPLE Learning "Enjoy Sport": Training on weather/temp/wind examples with +(enjoy) and -(don't enjoy). Find-S outputs: ⟨Sunny, ?, ?, Strong, ?, ?⟩ — most specific pattern consistent with all positive examples.

Concept learning provides the theoretical foundation for supervised learning — the algorithms studied in modern ML are sophisticated implementations of hypothesis space search.

ID3 Algorithm — Full Answer with Worked Example
B · Exam Answer Format (include this calculation)
ID3 (Iterative Dichotomiser 3) is a decision tree learning algorithm that constructs the tree by recursively selecting the attribute with the highest Information Gain to split training examples.
  • Entropy: H(S) = −∑ pᵢ log₂(pᵢ). For binary class [+14, −9]: H = −(14/23)log₂(14/23) − (9/23)log₂(9/23) = ~0.94 bits.
  • Information Gain: IG(S,A) = H(S) − ∑(|Sᵥ|/|S|)·H(Sᵥ). Select attribute with maximum IG as root node.
  • Algorithm Steps: If all same class → leaf. Else: compute IG for all attributes → split on max IG → recurse on branches → until pure leaves or no attributes.
  • Issues: Overfitting (pruning required); bias toward multi-valued attributes (C4.5 uses Gain Ratio to fix); doesn't handle continuous attributes natively.
ID3 is foundational for decision tree learning — understanding it in detail covers C4.5 and CART as well, since both are refinements of the same core mechanism.

★ NEW: Types of Gradient Descent + Delta Rule 10 marks · 2024-25
A · Conceptual Understanding

Gradient Descent minimizes the loss function by moving weights in the direction of steepest descent (negative gradient). Three variants:

  • Batch Gradient Descent: Computes gradient over entire training dataset → one weight update per epoch. Stable but slow on large datasets (must process all data before updating).
  • Stochastic Gradient Descent (SGD): Computes gradient and updates weights after every single training example. Fast, noisy — can escape local minima but oscillates. Used in online learning.
  • Mini-Batch Gradient Descent: Processes k examples (mini-batch) at a time — compromise between batch and SGD. Most commonly used in practice (k=32, 64, 128).

Delta Rule (Widrow-Hoff Rule): Learning rule for adjusting weights in a single-layer network (no hidden layers). Weight update: Δwᵢ = η × (t - o) × xᵢ where η = learning rate, t = target, o = actual output, xᵢ = input. Minimizes mean squared error — equivalent to gradient descent for linear networks.

B · Exam Answer Format
Gradient Descent is an iterative optimization algorithm that minimizes the loss function by updating model weights proportional to the negative gradient of the loss with respect to each weight.
Type Data per Update Speed Stability

SGD 1 example Fast Noisy/unstable
Mini-Batch GD k examples Balanced Moderately stable
  • Delta Rule: Δwᵢ = η(t−o)xᵢ — updates weight proportional to prediction error; equivalent to gradient descent on MSE for linear activation units.
  • Backpropagation generalizes Delta Rule to multilayer networks using chain rule — Delta Rule applies only to output layer; backprop extends error attribution to hidden layers.
Mini-batch gradient descent with adaptive learning rates (Adam optimizer) is the dominant training approach in modern deep learning, combining the stability of batch GD with the speed of SGD.

★ NEW: RL — 3 Different Models 10 marks · 2024-25
B · Exam Answer Format
Reinforcement Learning models are classified by how the agent learns its policy — through an internal model of the environment, direct value estimation, or direct policy search.
  • Model-Based RL: Agent learns an internal model of the environment (transition function T and reward function R). Uses this model to plan ahead via simulated rollouts. Faster learning but model errors compound. Example: Dyna-Q, AlphaZero.
  • Model-Free RL: Agent learns directly from interaction without building an environment model. Subdivided into: Value-based (learns value function — Q-Learning, SARSA) and Policy-based (learns policy directly — REINFORCE). More robust, less data-efficient. Example: DQN, PPO.
  • Policy Gradient Methods: Directly parameterize and optimize the policy π(a|s;θ) using gradient ascent on expected cumulative reward. Handles continuous action spaces — essential for robotics.
